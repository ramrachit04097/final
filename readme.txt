# MeetFlow – Quick Guide

MeetFlow helps companies turn **meetings into tasks and track employee progress**.

### 👨‍💼 Manager

1. **Sign Up** as Manager with company and personal details.
2. **Log In** using your User ID and Password.
3. View the **Manager Dashboard**.
4. Approve employee registration requests.
5. Start a meeting and **record it**.
6. Generate the **meeting transcript**.
7. Click **Analyze with AI** to find actionable tasks.
8. Review and edit the AI-generated tasks.
9. Approve and **assign tasks** to employees.
10. Track **Pending, In Progress, Completed and Overdue** tasks.

### 👨‍💻 Employee

1. **Sign Up** as Employee with employee and company details.
2. Wait for **Manager Approval**.
3. Log In after approval.
4. View only your **assigned tasks and alerts**.
5. Update task status:
   **Pending → In Progress → Completed**

### 🤖 AI Assistant

* Managers can ask about company tasks, employees and meetings.
* Employees can ask about their own tasks and information.
* AI only uses data the user is allowed to access.

### 🔄 Main Workflow

**Meeting → Transcript → AI Analysis → Manager Review → Task Assignment → Employee Work → Progress Tracking**

### 🔐 Security

MeetFlow uses **role-based access and company-level data isolation** so employees cannot access other employees' private tasks.
