# MeetFlow

**MeetFlow** is a meeting and task management platform that helps teams turn **meeting conversations into actionable tasks** and track employee progress in one place.

---

# 🚀 How MeetFlow Works

**Meeting → Transcript → AI Analysis → Manager Review → Task Assignment → Employee Execution → Progress Tracking**

---

# 👨‍💼 Manager

### **1. Sign Up**
Select **Manager** and create your account using company details, manager details, company email, personal email, User ID, and password.

### **2. Login**
Use your **User ID and Password** to access the Manager Dashboard.

### **3. Manage Employees**
Managers can view employee registration requests and **approve or deny** employees.

### **4. Conduct Meetings**
Managers can start and record meetings using the microphone.

### **5. Generate Transcript**
The recorded meeting is converted into a text transcript.

### **6. Analyze with AI**
The Manager can choose **Analyze with AI** to identify actionable tasks from the meeting.

### **7. Review Tasks**
AI-generated tasks are **not automatically assigned**. The Manager can review, edit, remove, or approve tasks.

### **8. Assign & Track**
Approved tasks are assigned to employees. Managers can track **Pending, In Progress, Completed, and Overdue** tasks.

---

# 👨‍💻 Employee

### **1. Sign Up**
Select **Employee** and enter employee name, employee ID, designation, company details, emails, User ID, and password.

### **2. Wait for Approval**
The employee account remains **Pending** until the Manager approves the registration.

### **3. Login**
After approval, the employee can log in using their User ID and Password.

### **4. View Tasks**
Employees can see their assigned tasks, deadlines, and alerts.

### **5. Update Progress**
Employees can update their task status:

**Pending → In Progress → Completed**

---

# 🤖 AI Assistant

MeetFlow includes an AI assistant.

**Managers** can ask about authorized company information such as employees, tasks, meetings, deadlines, progress, and alerts.

**Employees** can ask about their own tasks, deadlines, status, and alerts.

The AI only accesses information the user is authorized to see.

---

# 🔔 Alerts

MeetFlow provides alerts for:

- Upcoming meetings
- Approaching deadlines
- Overdue tasks
- Important pending work

---

# 🔐 Security

MeetFlow uses **role-based access control** and **company-level data isolation**.

- Managers can access their company's data.
- Employees can access their own permitted information.
- Employees cannot access other employees' private tasks.
- AI responses are restricted according to user permissions.
